# Presentation videos

Both presentation recordings are provided in this directory and as separate playable files in
the Canvas group submission ZIP.

| Recording | Coverage | Required duration |
| --- | --- | --- |
| [Promotion video](IRS-PM-2026-08-17-AIS08FT-GRP-36-IntelliHire-AI-Promotion.mp4) | Business pain and value, use-case demo, pricing | 5 minutes |
| [System-design video](IRS-PM-2026-08-17-AIS08FT-GRP-36-IntelliHire-AI-System.mp4) | High-level system design and technical explanation of use cases | 5 minutes |

The repository stores MP4 files with Git LFS. To retrieve playable recordings from a clone,
install Git LFS and run `git lfs pull`. A source ZIP may contain small LFS pointer files;
the standalone MP4 files in the Canvas package are the playable submission copies.

The recordings are also linked from the root README. The course specification does not allow
AI-generated presentation speech.
